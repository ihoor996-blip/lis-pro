LIS PRO — сайт-прототип
1. Розпакуйте ZIP.
2. Відкрийте index.html у браузері для перегляду.
3. У script.js замініть YOUR_EMAIL@example.com на адресу для отримання заявок.
4. Завантажте всі файли та папку assets на хостинг.

ВАЖЛИВО:
- Це фронтенд-прототип. Форма поки що формує email через поштову програму.
- Файли не завантажуються на сервер автоматично.
- Немає захищеної адмін-панелі та Telegram-сповіщень.
- Для реального приймання заявок, зберігання файлів, адмін-панелі та сповіщень потрібен бекенд/сервіс форм і налаштування доступів.
- Перед публікацією додайте реальні контакти, політику конфіденційності та перевірте ціни/умови послуг.
